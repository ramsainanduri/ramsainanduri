### `$ whoami`

I turn biological questions into dependable software for clinical genomics in Lund, Sweden. My usual habitat sits somewhere between a sequencer, a terminal, and a web browser—building systems that help people move from raw data to evidence they can trust.

DNA and RNA are the domain. Engineering is the craft.

- 🧬 Building and maintaining clinical workflows for solid tumours, haematological malignancies, pharmacogenomics, rare disease, and RNA analysis
- 🖥️ Developing full-stack analysis and interpretation tools with **Python, FastAPI, React, TypeScript, MongoDB, Redis, and Celery**
- ⚙️ Orchestrating reproducible pipelines with **Nextflow** and **Snakemake**, then persuading containers and HPC schedulers to behave
- 🧪 Designing validation tooling, automated tests, QC systems, and release workflows—because “it ran once” is not a validation strategy
- 📦 Working across APIs, databases, Docker/Singularity, CI/CD, documentation, and production deployments
- 🔭 Currently modernising clinical web applications, hardening pipeline reproducibility, and making complex results easier to inspect

> I tinker with DNA and RNA. I engineer everything around them so the tinkering is reproducible.
